# 附录 C 术语表

| 术语           | 本书含义                                  |
|----------------|-------------------------------------------|
| 数据平面       | 实际接收、治理与转发请求的运行组件        |
| 控制平面       | 管理、校验和发布配置的组件                |
| 插件链         | 按契约交接请求控制权的一组扩展处理器      |
| 选择器         | ShenYu 某插件下的范围选择对象             |
| 规则           | 选择范围中的进一步条件与策略参数          |
| 舱壁           | 限制某依赖占用并发等资源的隔离机制        |
| 半开           | 熔断器恢复前受限探测的状态                |
| 负缓存         | 保存“未匹配”或“不存在”的缓存结果          |
| revision       | 发布协议中的单调版本标识                  |
| 背压           | 下游处理能力对上游生产速度的约束机制      |
| Wasm           | WebAssembly，一种可用于代理扩展的执行格式 |
| xDS            | Envoy 动态配置相关协议族                  |
| Gateway API    | Kubernetes 面向服务网络的资源 API 体系    |
| ReferenceGrant | 授权特定跨命名空间引用的 Gateway API 资源 |
